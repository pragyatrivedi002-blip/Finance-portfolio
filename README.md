## 📊 Infosys Limited – 5-Year Financial Performance Dashboard

### Project Overview

A five-year financial performance analysis of *Infosys Limited* covering *FY 2022 to FY 2026*. The project converts financial statement data into a Power BI dashboard to analyse the company's financial performance and key financial trends.

### 🎯 Objectives

- Analyse revenue and revenue growth
- Evaluate net profit and profitability trends
- Analyse assets, equity and liabilities
- Examine operating, investing and financing cash flows
- Calculate and analyse key financial ratios
- Identify major financial trends over five years

### 🛠️ Tools Used

- Microsoft Power BI
- Microsoft Excel
- Financial Statement Analysis
- Ratio Analysis
- Data Visualization

### 📈 Dashboard Includes

- Revenue Trend
- Net Profit Trend
- Assets vs Liabilities
- Cash Flow Analysis
- Key Financial Ratios
- Revenue Growth
- Profit Growth
- Net Profit Margin
- Liability-to-Equity
- CAGR Analysis

### 🖼️ Dashboard Preview

The dashboard provides a visual summary of Infosys Limited's five-year financial performance.
